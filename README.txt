САЙТ-ПОРТФОЛИО АКТАНА

Как запустить:
1. Распакуйте ZIP-архив.
2. Откройте файл index.html в браузере (двойной клик).
Интернет нужен только для ссылки на Instagram.

Структура:
index.html     - страница сайта
css/style.css  - стили
js/script.js   - JavaScript
images/photo.jpg - фото для раздела «Обо мне»
images/favicon.svg, favicon.png - иконка во вкладке браузера

JS-функции:
1. Мобильное меню - на телефоне кнопка «Меню» открывает и закрывает навигацию.
2. Тёмная и светлая тема - кнопка в меню переключает цвета сайта и меняет свою надпись.

Форма: поля проверяет сам браузер (required), кнопка «Отправить» открывает письмо на почту.
